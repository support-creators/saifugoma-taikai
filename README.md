## 競技内容

1. **予選** — 参加者全員でさいふごまを回し、長く回っていた上位16名が決勝へ進みます。
2. **決勝トーナメント「けんかごま」（3回戦）** — 一方が先に投げ、もう一方が後から投げ、最後まで回っていた方が勝ち。次は投げる順番を入れかえ、2勝した方の勝ちです（1対1の場合は同時に投げます）。
